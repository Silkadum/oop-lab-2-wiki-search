# Поиск по Википедии

Консольная программа для поиска статей в русской Википедии. Пользователь вводит запрос, программа выводит список найденных статей и открывает выбранную в браузере.

Практическая работа №2 по дисциплине «Объектно-ориентированное программирование», СПбГЭТУ «ЛЭТИ».

## Требования

- Python 3.10 или новее
- Доступ в интернет

## Установка

```bash
git clone https://github.com/Silkadum/oop-lab-2-wiki-search.git
cd oop-lab-2-wiki-search
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Использование

1. Введите поисковый запрос, например `ЛЭТИ`.
2. Программа выведет до 10 статей с номерами и коротким фрагментом текста.
3. Введите номер статьи — она откроется в браузере, а ссылка будет напечатана в консоли.

Команды начинаются с `/` и работают в любом регистре:

| Команда | Действие |
|---|---|
| `/помощь` | показать список команд |
| `/назад` | вернуться к новому поиску (при выборе статьи) |
| `/выход` | завершить программу |

Программу также можно завершить сочетанием `Ctrl+C`.

## Структура проекта

```
├── main.py              # точка входа: создаёт объекты и запускает приложение
├── app.py               # SearchApp — управляет циклом поиска и выбора статьи
├── search_result.py     # SearchResult — найденная статья
├── wikipedia_client.py  # WikipediaClient — запрос к API Википедии
├── response_parser.py   # ResponseParser — разбор JSON-ответа
├── wikipedia_error.py   # WikipediaError — ошибки сети и API
├── console_input.py     # ConsoleInput — ввод и проверка формата
├── console_output.py    # ConsoleOutput — вывод результатов и сообщений
└── browser_opener.py    # BrowserOpener — ссылка на статью и открытие в браузере
```

## Запуск в WSL

В WSL браузер Windows по умолчанию не открывается из Linux. Если после выбора статьи ничего не происходит, установите `wslu` и укажите его как браузер:

```bash
sudo apt install wslu
echo 'export BROWSER=wslview' >> ~/.bashrc
source ~/.bashrc
```

Ссылка на статью в любом случае печатается в консоли, и её можно открыть вручную.
