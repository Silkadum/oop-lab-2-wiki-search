# Поиск по Википедии

Консольное приложение на Python для поиска статей в русской Википедии. Программа принимает запрос, показывает до 10 результатов с заголовками и короткими фрагментами текста, а выбранную статью открывает в браузере. Ссылка на статью также выводится в консоли.

**Практическая работа № 2 по дисциплине «Объектно-ориентированное программирование»**  
СПбГЭТУ «ЛЭТИ»

## Требования

- Python 3.10 или новее
- Git для клонирования репозитория
- Доступ к интернету для установки зависимостей и поиска статей

## Установка

Склонируйте репозиторий и установите зависимости из `requirements.txt`.

```bash
git clone https://github.com/Silkadum/oop-lab-2-wiki-search.git
cd oop-lab-2-wiki-search
python -m pip install -r requirements.txt
```

## Запуск

Выполните команду из папки проекта.

```bash
python main.py
```

## Использование

1. Введите поисковый запрос, например `ЛЭТИ`.
2. Просмотрите результаты. У каждой статьи есть номер и заголовок. Если Википедия вернула фрагмент текста, он появится под заголовком.
3. Введите номер нужной статьи. Программа напечатает ссылку и попробует открыть её в браузере.
4. Введите новый запрос, чтобы продолжить поиск, или `/выход`, чтобы завершить работу.

### Пример поиска

В примере список результатов сокращён.

```text
Поиск: ЛЭТИ
Найдено статей: 10
1. Санкт-Петербургский государственный электротехнический университет
2. Мемориальный музей А. С. Попова (ЛЭТИ)
…
Номер статьи (1–10) или /назад: 1
Открываю «Санкт-Петербургский государственный электротехнический университет»: https://ru.wikipedia.org/w/index.php?curid=11099
```

### Команды

| Команда | Действие |
| --- | --- |
| `/помощь` | Показать список команд |
| `/назад` | Вернуться к вводу запроса во время выбора статьи |
| `/выход` | Завершить работу |

Команды работают в любом регистре. Программу также можно завершить сочетанием `Ctrl+C`.

### Обработка ошибок

| Ситуация | Что произойдёт |
| --- | --- |
| Пустой запрос или строка из пробелов | Программа попросит ввести запрос заново |
| По запросу ничего не найдено | Программа сообщит об этом и предложит выполнить новый поиск |
| Вместо номера введён текст или число вне диапазона | Программа попросит снова выбрать статью из текущего списка |
| Википедия недоступна или не отвечает | Программа покажет сообщение об ошибке и вернётся к вводу запроса |
| Браузер не открылся | Ссылку можно открыть вручную из консоли |

## Как работает поиск

1. `ConsoleInput` читает запрос и убирает пробелы по краям строки.
2. `WikipediaClient` отправляет запрос к MediaWiki API через `requests`. Поисковая строка передаётся как параметр HTTP-запроса, а библиотека кодирует её для URL.
3. `ResponseParser` разбирает JSON-ответ, убирает HTML-теги из фрагментов и создаёт объекты `SearchResult`.
4. `ConsoleOutput` показывает результаты, а `SearchApp` управляет выбором статьи и переходом к следующему запросу.
5. `BrowserOpener` формирует ссылку по идентификатору статьи (`pageid`) и передаёт её браузеру через стандартный модуль `webbrowser`.

## Структура проекта

```
├── main.py              # точка входа: создаёт объекты и запускает приложение
├── constants.py         # константы: адреса Википедии, параметры запроса, команды
├── app.py               # SearchApp — управляет циклом поиска и выбора статьи
├── search_result.py     # SearchResult — найденная статья
├── wikipedia_client.py  # WikipediaClient — запрос к API Википедии
├── response_parser.py   # ResponseParser — разбор JSON-ответа
├── wikipedia_error.py   # WikipediaError — ошибки сети и API
├── console_input.py     # ConsoleInput — ввод и проверка формата
├── console_output.py    # ConsoleOutput — вывод результатов и сообщений
└── browser_opener.py    # BrowserOpener — ссылка на статью и открытие в браузере
```
